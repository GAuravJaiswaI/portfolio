# Gaurav Jaiswal - Portfolio

A modern, performant portfolio website built with React, TypeScript, and Tailwind CSS.

## 🚀 Features

- **Modern Tech Stack**: React 18, TypeScript, Vite, Tailwind CSS
- **Responsive Design**: Mobile-first approach with smooth animations
- **Performance Optimized**: Lazy loading, code splitting, and web vitals monitoring
- **SEO Friendly**: Meta tags, structured data, and sitemap
- **Accessible**: WCAG compliant with semantic HTML
- **Cross-Platform Design System**: Shared tokens for React and React Native

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel/Netlify

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio.git

# Navigate to the project
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🏗️ Project Structure

```
src/
├── app/              # Main app component
├── components/       # Reusable components
│   ├── layout/      # Layout components
│   └── ui/          # UI primitives
├── sections/        # Page sections
├── theme/           # Design system
├── hooks/           # Custom React hooks
└── utils/           # Utility functions
```

## 🎨 Design System

The project uses a shared design system that can be used across React and React Native:

- **Colors**: Minimal palette with primary and accent colors
- **Typography**: Inter font with consistent scale
- **Spacing**: 8px grid system
- **Components**: Button, Text, Section components
